# Domain modules

Create a module only when it supports an approved vertical slice. The first modules are `identity`, `trainers`, `clients`, `exercises`, `programs`, `assignments`, `workouts`, and `showcase`.

Later modules (`billing`, `chat`, `notifications`, `metrics`, `competitions`, `commerce`, `gamification`, `ai`) must not be scaffolded as empty folders. Each needs an accepted scenario, data owner, API contract, migration and tests.
